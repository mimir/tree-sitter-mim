# Tree-Sitter Grammar for MimIR

[![CI](https://img.shields.io/github/actions/workflow/status/mimir/tree-sitter-mim/ci.yml?branch=main&label=tests&logo=github)](https://github.com/mimir/tree-sitter-mim/actions/workflows/ci.yml)

## Development

`grammar.js` and `src/scanner.c` are the only hand-written sources; `src/parser.c`, `src/grammar.json`,
`src/node-types.json` and the language bindings are generated by the tree-sitter CLI and committed, so
every change to `grammar.js` has to be followed by a regeneration:

```sh
tree-sitter generate      # or: make generate
tree-sitter test          # or: make test, which regenerates first if grammar.js is newer
```

`make` builds the static and shared C libraries plus the pkg-config file, `make install` installs them
along with `queries/`, and `make clean` removes the build artifacts again (but never the generated
`src/`).  `nix develop` provides the tree-sitter CLI, node and graphviz.

## Integrations

### Helix

Helix integration is currently available in [my fork](https://github.com/amaebel/helix/tree/mim/runtime/queries/mim). There is currently no plan to upstream the changes as MimIR is not (yet) relevant to the public and the grammar itself does not handle all of its grammar properly.
This will be moved to a plugin once plugin support lands in helix master.

### VSCode

A VSCode plugin is available [here](https://marketplace.visualstudio.com/items?itemName=MimIRExtensions.tree-sitter-mim-vscode)

### Neovim

Neovim does not know about Mim yet, so `nvim-treesitter` (branch `main`) has to be told about this
repository.  Unlike Helix, Neovim uses the queries in [`queries/`](queries) - capture names differ
between the two editors, so the Helix queries linked above will *not* work here.

[vim-mim](https://github.com/mimir/vim-mim) already does step 1 for you and adds what a grammar
cannot provide - filetype detection, comment settings, and abbreviations for the Unicode terminals -
plus a regex syntax file that Neovim falls back to whenever the parser is missing.  With it installed,
only step 2 is left.

1. Add the following to your `init.lua`:

  ```lua
  vim.filetype.add({
      extension = { mim = "mim" },
  })

  vim.api.nvim_create_autocmd("User", {
      pattern = "TSUpdate",
      callback = function()
          require("nvim-treesitter.parsers").mim = {
              install_info = {
                  url = "https://github.com/mimir/tree-sitter-mim",
                  queries = "queries",
              },
          }
      end,
  })
  ```

2. Run `:TSInstall mim` inside of Neovim.  This downloads the repository, compiles `src/parser.c` and
   installs `queries/`.  `:TSUpdate mim` pulls a newer version later on.

3. `nvim-treesitter` `main` does not enable highlighting by itself.  Distributions such as LazyVim do
   it for you; otherwise add

  ```lua
  vim.api.nvim_create_autocmd("FileType", {
      pattern = "mim",
      callback = function()
          vim.treesitter.start()
      end,
  })
  ```

#### Working on the grammar

Point `install_info` at a local clone instead - `queries/` is then *symlinked* into Neovim's parser
directory, so edits to the `.scm` files take effect right away and only `:TSInstall! mim` is needed
after a change to `grammar.js`:

```lua
install_info = {
    path = vim.fn.expand("~/treesitter/tree-sitter-mim"),
    queries = "queries",
    generate = false,
    generate_from_json = false,
},
```
